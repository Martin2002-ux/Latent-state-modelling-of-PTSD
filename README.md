# Latent-state-modelling-of-PTSD
“recreating_cochran_cisler_simulations” contains the code to recreate all analyses performed in Cochran and Cisler (2019) using the updated latent state model and the new baseline hyperparameters. It shows that the updated model and hyperparameters can recreate all the phenomena tested in Cochran and Cisler (2019) except for the “memory modification” effect.

“main_analysis” contains the code we used to simulate all experiments and generate the results we put into the various tables. This code runs each simulated experiment 1000 times.

"simplified_analysis" contains the same core code as main_analysis, but is configured to run a single simulation instead of 1,000. This makes it useful for exploratory hyperparameter tuning, since results can be inspected quickly with the built-in plotting functions. All results reported in the paper come from main_analysis; simplified_analysis is kept for convenience, both for reproducing individual figures and for exploring how hyperparameter choices affect outcomes.

To recreate the figure for a given study: first run the settings section (marked ###settings### to ###stop), then run the code for your study of interest, up through the plot_compare() function. If the study includes a next-day recall phase and you want a plot showing only acquisition and extinction, a few additional changes are needed. Delete the section of phase_def referring to the recall phase. Remove the ezITI argument from the run() function. In some studies, you will also need to edit the block argument of run() so it includes only one number per phase, removing any number(s) corresponding to the recall phase, and will also need to edit the features argument so all letters are present in the shortened experiment.
